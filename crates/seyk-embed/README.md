# seyk-embed

Model-independent embedding interfaces and values.

Defines `Embedder`, `EmbeddingRequest`, `ResourceInput`, embedding vectors and
Photo Anchor quantization. This crate has no inference runtime, search engine
or model downloads.

```toml
[dependencies]
seyk-embed = "0.2.0"
```
