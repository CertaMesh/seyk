# seyk-core

Local search, evidence and cache engine.

Provides hybrid retrieval, resources, exact locations and hash-verified
extraction. Uses `seyk-embed` interfaces without an inference backend.
Optional features add `audio`, `pdf`, `pdf-render` and `watch` support.
Source content, queries and vectors stay local.

```toml
[dependencies]
seyk-core = "0.1.0"
```
